### What did this work change about who I want to be as a software developer?

Honestly I don't really like this trend but I feel like I need to accept it - being able to write sophiscated code or algorithm is not an advantage anymore. The AI built all the algos used in this project without sweating a bit, including the Contraction Hierarchy prebuild and query, albeit a very simple one. The point is if one works in the software industry, they don't even have a chance to write code anymore - AI is simply faster, higher quality, and much more cost efficient. Then what's left for us? One could argue that it's only the junior developers being replaced, but that's not true... AI already have the planning and orgnizing ability of a mid-level engineer with adequate skill and harness, and it won't take long to replace senior engineers. I think the only thing remaining hard to replace in software will be design, and that's because there's no way to judge a design totally objectively (or in lecture 3's sense: no universal sensor for designs).
